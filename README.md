## [mini-regvelo](mini-regvelo/)：RegVelo（Cell, 2026）论文的学习实现

**这篇论文要解决的问题**：单细胞测序会同时测到每个细胞的未剪接 RNA（u）和已剪接 RNA（s），
但这些只是**某一时刻的静态快照**，不知道细胞处在发育的哪个阶段。
RegVelo 要在同一个模型里同时反推出两件事：

1. 每个细胞处在发育过程的什么位置（潜时间）；
2. 基因之间谁调控谁（调控网络）。

**论文的关键想法**：传统的 RNA velocity 方法只看每个基因自身的 u/s 关系，
默认基因之间互不影响。RegVelo 把"调控网络"直接接进转录速率：

```
转录速率 α = softplus(Ws + b)
```

其中 s 是当前所有基因的表达水平，W 就是待学习的调控矩阵。
这样基因之间通过 W 相互耦合，不再是各自独立的方程。

**本项目做了什么**（教学版最小实现）：

- 完整的核心流程：输入观测 `(U_obs, S_obs)` 与先验图 `G_prior`，
  输出潜时间、耦合的 RNA 常微分方程、重建损失，并据此更新参数。
- 六个单元测试：解析解对照、时间梯度与权重梯度的有限差分检验、
  先验掩码（硬约束）、以及敲除逻辑的方向性。
- 一次 400 轮训练的完整记录：指标、训练历史、六张诊断图，以及训练好的模型参数。
- [`mini-regvelo/README.md`](mini-regvelo/README.md)：逐个模块说明代码的作用、
  每个文件背后的数学，并明确列出本教学版相对论文原版做了哪些简化。
- [`mini-regvelo/ENVIRONMENT_NOTES.md`](mini-regvelo/ENVIRONMENT_NOTES.md)：
  运行环境、验证结果，以及六张图能说明和不能说明什么。

**这次运行的核心结论**：模型几乎完美地重建了观测数据（每个矩阵的重建 MSE 约 1.6e-4），
却只找回了三条真实调控边中的一条。也就是说，
**重建误差低，并不能作为"已识别出真实调控网络"的证据**——
这解释了论文原版模型为什么必须引入变分推断和额外的动力学正则项。
